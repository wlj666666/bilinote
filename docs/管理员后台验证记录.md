# 管理员后台验证记录

验证日期：2026-11-04。

## 交付范围与入口

- `/admin`：系统总览、基础资源卡片、服务状态及最近失败任务。
- `/admin/tasks`：视频笔记与网页问答任务的分页查询、筛选和详情；视频排队取消及失败重试。
- `/admin/users`：用户查询、创建、启停、密码重置及用户任务跳转。
- 首页和原设置导航中均增加管理后台入口；沿用管理员登录权限。

## 数据来源

| 展示内容 | 来源与口径 |
| --- | --- |
| 视频任务计数、状态和筛选 | SQLite 中当前未删除的任务及其最新 `TaskJob` 状态；旧任务使用启动时补齐的元数据 |
| 用户信息与任务数 | 用户表及按用户分组统计的未删除视频任务 |
| 问答监控 | 后端当前保留的 `ChatJob` 记录，不包含未形成任务记录的旧同步调用 |
| CPU、内存 | Linux `/proc`；可读取时使用 cgroup 配额及用量，并标注范围 |
| GPU、显存 | `nvidia-smi`；无监测工具、读取失败或字段不支持时显示不可用或未知 |
| 磁盘 | 数据库所在文件系统的实际容量及剩余空间 |
| 服务状态 | 当前响应、调度线程及心跳/最近循环结果、推理子进程存活状态 |

总览不使用模拟数据；访问后台不会预加载用户笔记正文。资源最多缓存 5 秒，页面每 10 秒刷新；请求失败会显示过期提示，资源值与服务健康状态不会继续显示正常。
