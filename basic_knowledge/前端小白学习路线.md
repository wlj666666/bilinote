# 前端小白学习路线：理解浏览器、Vite 与 FastAPI

你不需要一开始就学习很深的计算机网络。为了搞清楚当前项目是怎么从“运行命令”变成“浏览器页面”的，建议按下面的顺序学习。

## 第一阶段：先建立整体地图

首先分清这几个角色：

```text
前端源代码
   │
   ▼
Vite 开发服务器
   │ 通过 HTTP 返回文件
   ▼
浏览器执行前端代码
   │ 通过 HTTP 调用 API
   ▼
FastAPI 后端服务器
```

重点理解以下术语：

- 程序与进程
- 客户端与服务器
- IP 地址与端口
- 请求与响应
- 前端与后端

达到这个目标就够了：

> 能说清浏览器、Vite 和 FastAPI 分别运行在哪里，以及它们怎么通信。

## 第二阶段：HTML、CSS、JavaScript

这是前端最核心的基础。

### HTML：页面有什么

```html
<button>提交</button>
```

HTML 描述页面结构，例如标题、输入框、按钮和图片。

### CSS：页面长什么样

```css
button {
  color: white;
  background: blue;
}
```

CSS 负责颜色、大小、位置、间距和布局。

### JavaScript：页面怎么动

```javascript
button.addEventListener("click", () => {
  alert("点击了按钮");
});
```

JavaScript 负责交互、计算、更新页面以及请求后端。

可以简单记成：

```text
HTML        骨架
CSS         外观
JavaScript  行为
```

需要重点掌握：

- 变量、函数、数组、对象
- 条件判断和循环
- DOM 与事件
- `async/await`
- `fetch()`
- ES Module 中的 `import` 和 `export`

## 第三阶段：浏览器如何加载页面

你不需要先研究浏览器内核，只需理解以下流程：

```text
输入 URL
  ↓
建立 TCP 连接
  ↓
发送 HTTP 请求
  ↓
收到 HTML
  ↓
继续请求 CSS、JavaScript、图片
  ↓
解析并渲染页面
  ↓
执行 JavaScript
```

建议学习这些概念：

- URL 的组成
- HTTP 请求与响应
- GET 和 POST
- 请求头、请求体、状态码
- 浏览器开发者工具中的 Network、Console、Elements

其中浏览器开发者工具非常重要。它能让原本看不见的通信过程变得可见。

## 第四阶段：Node.js、npm 与 Vite

这是初学者最容易混淆的部分。

需要先记住：

- **Node.js**：让 JavaScript 能够在浏览器外运行。
- **npm**：安装和管理项目依赖。
- **Vite**：开发期间处理并提供前端代码。
- **React**：用来编写浏览器界面的库。

常见命令：

```bash
npm install
npm run dev
```

大致含义是：

```text
npm install
    └── 安装项目依赖

npm run dev
    └── 启动 Node.js
         └── 运行 Vite
              └── 监听一个端口
```

需要了解这些文件：

```text
package.json       项目配置、依赖和命令
node_modules/      已安装的依赖
index.html         页面入口
src/main.*         JavaScript/React 入口
src/App.*          主要页面组件
vite.config.*      Vite 配置
```

初期不需要研究 Vite 内部实现，只要理解它做了三件事：

1. 监听端口。
2. 转换并返回前端文件。
3. 文件变化后热更新浏览器页面。

## 第五阶段：React

掌握 JavaScript 基础后，再学习 React。重点是：

- 组件
- JSX
- `props`
- `state`
- `useState`
- `useEffect`
- 事件处理
- 条件渲染
- 列表渲染
- 表单
- 组件之间传递数据

例如：

```jsx
function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      点击了 {count} 次
    </button>
  );
}
```

不要一开始就深入虚拟 DOM、Fiber、性能优化等内部原理。

## 第六阶段：前端如何调用后端

这是理解当前项目数据流的关键。

浏览器中的前端代码可能这样请求 FastAPI：

```javascript
const response = await fetch("http://127.0.0.1:8000/api/example");
const data = await response.json();
```

过程是：

```text
React 组件
  ↓ 调用 fetch()
浏览器
  ↓ HTTP 请求
FastAPI 接口
  ↓ 查询或计算
返回 JSON
  ↓
浏览器收到 JSON
  ↓
React 更新页面
```

需要学习：

- REST API 的基本概念
- JSON
- GET、POST
- 查询参数和请求体
- Promise 与 `async/await`
- 跨域 CORS
- Vite 代理配置
- 前后端错误处理

## 第七阶段：补充必要的网络知识

围绕实际开发学习即可：

- `127.0.0.1` 和 `localhost`
- IP 地址
- 端口
- socket 的基本概念
- TCP 连接
- HTTP 运行在 TCP 之上
- 回环接口
- `0.0.0.0` 与 `127.0.0.1` 的区别

暂时不必深入：

- TCP 拥塞控制
- 数据链路层
- 路由协议
- 浏览器内核源码
- 操作系统网络协议栈实现

## 最适合你的实践方法

直接用当前项目观察，比只看教程有效。

### 实验一：确认各个进程

分别启动前端和后端，然后理解：

```text
npm run dev              → Vite/Node.js 进程
python main.py 之类命令  → Python/FastAPI 进程
打开网页                 → 浏览器及渲染进程
```

### 实验二：观察页面资源

打开浏览器开发者工具的 Network 面板并刷新页面，观察：

- 第一个 HTML 请求
- JavaScript 文件
- CSS 文件
- 图片
- API 请求

点击某个请求，查看：

- Request URL
- Request Method
- Status Code
- Response

### 实验三：观察前后端数据

在前端找到一个 `fetch` 或请求库调用，再找到后端对应的 FastAPI 路由：

```text
前端请求地址
      ↓
后端路由
      ↓
后端返回 JSON
      ↓
前端接收数据
      ↓
页面显示数据
```

### 实验四：故意停止服务

- 停止 Vite：页面资源无法重新加载。
- 只停止 FastAPI：页面可能还能打开，但业务数据加载失败。
- 重新启动 FastAPI：API 请求恢复。

这个实验能够非常直观地区分前端开发服务器和后端服务器。

## 推荐学习顺序

```text
程序、进程、端口
        ↓
HTML + CSS
        ↓
JavaScript 基础
        ↓
浏览器与 HTTP
        ↓
Node.js + npm + Vite
        ↓
React
        ↓
fetch + FastAPI + JSON
        ↓
CORS、代理和部署
```

现阶段最重要的是先抓住一句话：

> 前端源代码保存在硬盘上，Vite 读取并处理它，浏览器通过 HTTP 下载并执行它，运行中的前端再通过 HTTP 向 FastAPI 请求数据。

先把这条链路理解透，再沿着实际项目中的一个页面和一个 API 接口追踪代码，会比从头系统学习所有网络知识更容易。
