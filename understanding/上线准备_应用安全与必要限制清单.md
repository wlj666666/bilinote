# 上线准备：应用安全与必要限制清单

日期：2026-10-16  
状态：图片代理最小禁用名单已实现，通过自动化检查及真实公网联调；测试脚本按用户要求已删除。其他项目待实施。

## 目标与范围

保留现有视频转笔记、ASR／OCR、问答、历史记录等核心功能，修复已发现的应用安全问题，并控制用户对存储、GPU 和模型额度的消耗。

已有登录、管理员权限和用户数据隔离能力以验证为主。本清单不包含 Docker 部署、固定域名、定时备份或数据库迁移；代码和数据快照、凭据清理另行处理。

## 1. 修复图片代理

主要位置：`backend/app/routers/note.py` 中的 `image_proxy`、`backend/app/utils/image_proxy.py`。

按用户确认的“兼容性优先、宁可少禁止”的原则，采用最小禁用名单。该规则仅用于图片代理获取外部资源，不扩大到视频下载、模型接口或管理员配置的代理。

| 禁用目标 | 精确范围 |
| --- | --- |
| 本机名称 | `localhost` 及以 `.localhost` 结尾的域名，忽略大小写和末尾的点 |
| IPv4 本机回环 | `127.0.0.0/8` |
| IPv6 本机回环 | `::1` |
| 未指定地址 | `0.0.0.0`、`::` |
| 云内部元数据地址 | `169.254.169.254`、`fd00:ec2::254` |

- [x] 检查实际主机和 IP，不因路径、查询参数中出现相关文字而拦截。
- [x] 识别等价的数字 IPv4、IPv4 映射 IPv6 等写法。
- [x] 检查本地 DNS 解析结果；直连时连接到校验过的 IP，保留原始 Host、TLS 主机名和证书校验。
- [x] 允许正常跳转，对每一步目标重新执行同一名单检查，最多跳转 20 次。
- [x] 保留 HTTPX 环境代理、`NO_PROXY`、非标准端口及多平台图片来源。
- [x] 本地私有图片继续执行现有文件归属鉴权。

不添加平台域名白名单，也不整段禁止 `10.*`、`192.168.*`、IPv6 私网等地址。本次不新增图片大小限制，保留现有超时和图片类型检查；大小限制留待独立实施。

**边界：** 该方案是最小防护，不是完整 SSRF 防护。使用管理员配置的代理时，保留代理端解析域名的能力；本地 DNS 不可用时不会额外阻断代理请求，因此不能保证代理端的解析结果与本地检查一致。

**验收：** 模拟正常图片和跳转能够返回；禁用名称、IP、解析结果和跳转目标被拒绝；私有文件保持账号隔离。本机代理和仅代理端可解析的域名继续可用。

图片代理已完成自动化检查和公网联调；未调用付费模型，临时账号、会话、测试文件及辅助隧道已清理。

## 2. 验证现有权限和数据隔离

主要位置：`backend/app/services/auth.py`、`backend/app/routers/` 及用户数据服务。

- [ ] 未登录用户不能读取笔记、图片、文件和聊天等私有数据。
- [ ] 普通用户不能修改模型供应商、下载 Cookie、代理等管理配置。
- [ ] 用户 A 不能读取、下载、编辑、删除、重试用户 B 的任务，或访问其聊天、索引。
- [ ] 退出、停用账号和重置密码后，相应会话按预期失效。
- [ ] 普通用户收到的结果与错误信息不包含 API Key、Cookie 等凭据。

**验收：** 使用两个普通账号和一个管理员账号交叉测试，直接调用接口也无法越权。

## 4. 限制上传和媒体处理

主要位置：`backend/app/routers/note.py` 及下载、媒体解析、OCR 等处理入口。

| 项目 | 待实现行为 |
| --- | --- |
| 上传大小 | 接收过程中累计字节，超限停止并清理残留文件 |
| 文件有效性 | 除扩展名外，确认文件确实是可解析的音视频 |
| 视频时长 | 读取媒体信息后检查，超限时不进入昂贵处理 |
| 用户存储 | 达到用户存储额度后拒绝继续上传 |
| 输入规模 | 限制问题、补充提示词、预取字幕等内容的长度和数量 |
| OCR／抽帧 | 限制采样密度和总帧数，防止单任务产生过量计算 |

- [ ] 公网入口、Nginx 和后端的上传限制保持一致。
- [ ] 本地上传和远程视频均执行适用的媒体处理限制。

**验收：** 超限请求有明确提示，不留下大量半成品，也不继续进入转写或模型调用。
